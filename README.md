# Retro Coffee Arcade

Готовий статичний сайт для кав'ярні з 4 простими ретро-іграми:

- Coffee Snake
- Bean Catcher
- Coffee Memory
- Espresso Pong

Сайт не потребує бази даних, npm, сервера або збірки. Достатньо трьох файлів: `index.html`, `styles.css`, `app.js`.

## Як запустити локально

Просто відкрийте `index.html` у браузері.

Для коректнішої локальної перевірки можна запустити простий сервер:

```bash
python3 -m http.server 8080
```

Потім відкрити:

```text
http://localhost:8080
```

## Як викласти на GitHub Pages

1. Створіть новий GitHub-репозиторій, наприклад `retro-coffee-arcade`.
2. Завантажте в корінь репозиторію файли:
   - `index.html`
   - `styles.css`
   - `app.js`
3. Відкрийте `Settings` → `Pages`.
4. У `Source` виберіть `Deploy from a branch`.
5. Виберіть гілку `main` і папку `/(root)`.
6. Натисніть `Save`.
7. GitHub покаже адресу сайту виду:

```text
https://USERNAME.github.io/retro-coffee-arcade/
```

Саме цю адресу можна використати для QR-коду.

## Що легко змінити

У `index.html`:
- назву кав'ярні;
- тексти;
- назви ігор;
- опис головної сторінки.

У `styles.css`, блок `:root`:
- `--bg` — фон;
- `--cream` — основний світлий колір;
- `--accent` — теракотовий акцент;
- `--accent-2` — зелений ретро-акцент.

## Рекорди

Рекорди зберігаються в `localStorage` браузера. Це означає, що кожен відвідувач бачить власний локальний рекорд на своєму телефоні.

Якщо пізніше буде потрібен спільний рейтинг усіх гостей, для цього вже знадобиться зовнішня база даних або простий backend, наприклад Supabase/Firebase.
