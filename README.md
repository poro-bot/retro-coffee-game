# PORO Retro Games

Мобільна статична ретро-аркада для кав'ярні **PORO**.

## Що всередині

- **Coffee Snake** — керування свайпами, екранними кнопками або WASD/стрілками.
- **Bean Catcher** — чашка рухається за пальцем або мишею.
- **Coffee Memory** — керування тапами.
- **Espresso Pong** — платформа рухається за пальцем; також є кнопки та клавіатура.
- Рекорди зберігаються локально у браузері (`localStorage`).
- Немає серверної частини, бази даних, бібліотек або зовнішніх шрифтів.
