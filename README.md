# PORO Retro Arcade v3

Готовий статичний сайт для GitHub Pages. Сервер, база даних та збірка не потрібні.

## Що є у версії v3

- 6 ретро-ігор у сітці 2 × 3:
  - Coffee Snake
  - Bean Catcher
  - Coffee Memory
  - Espresso Pong
  - Cup Stack
  - Coffee Breakout
- мобільне керування:
  - Snake — свайпи
  - Catcher — ведення чашки пальцем
  - Pong — ведення платформи пальцем
  - Memory — тапи
  - Cup Stack — один тап
  - Breakout — ведення платформи пальцем
- кнопки та клавіатура як запасне керування;
- локальне збереження рекордів у браузері;
- опціональні прості 8-bit звуки;
- клікабельна назва гри зі стрілкою ← повертає до головного меню;
- оригінальний піксельний маскот у синьо-фіолетовій палітрі;
- маскот реагує на тап, а в кінці гри має happy/sad стани;
- зовнішніх бібліотек, шрифтів або зображень немає.
