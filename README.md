# PORO Halloween Arcade

6 геловінських ігор: Ghost Snake, Candy Catch, Monster Memory, Bat Bounce, Pumpkin Stack, Haunted Breakout.

Статичний сайт для GitHub Pages. Відкрийте index.html або завантажте всі три файли (index.html, styles.css, app.js) в одну папку.

На iOS Safari: вимкнено виділення елементів керування, додано touch-action та резервні touch-події для старих WebView. Рекорди зберігаються локально, якщо браузер дозволяє.
